# T185 / C201：原平均势与弱状态的极限配对

对照原稿 `eq:conv-potential-consistency`、附录实际势配对以及 `eq:conv-limit-identity` 中的势项。三模块七声明；AUXILIARY，17/26，原稿不变。

实际有界乘子对真实L²类的乘法交换身份给误差分解：a v−b φ = a(v−φ)+φ(a−b)。因此真实L²范数由 a.bound·‖v−φ‖+φ.bound·‖a−b‖控制。若原平均势保持同一上界并强L²趋于b，测试序列v强L²趋于固定有界测试φ，则同一乘积a_n v_n强L²趋于bφ。没有要求原状态强收敛，也没有额外要求所有v_n的L∞统一界。

对任意实Hilbert空间，显式统一范数界和所有固定测试的弱收敛，加上第二因子强收敛，给真实内积极限。势的真实自伴乘法将(b_n u_n,v_n)改写为(u_n,b_n v_n)，上述强乘积结果清偿变化测试，最终得到(by,φ)。

两个具体定理分别使用原有限元fixedTimePotential及原差分fixedSpacetimePotential。平均势强收敛由T184/T183内部供应、原同一界由真实重构保界供应，不再把势一致性作为调用者前提。有限元仅需dt→0及有限空间测度；差分保留固定原盒与独立h、dt细化。

显式输入仍包括状态范数统一有界、其真实弱极限和测试强逼近；本批仅清偿原控制极限证明中的势项，尚未从离散状态方程证明这些输入、梯度/时间项或端点。固定φ允许任意有界可测测试，包含原光滑有限和；没有偷换原势或离散乘法对象。七项全部根导入并审计，固定SHA交独立Agent。

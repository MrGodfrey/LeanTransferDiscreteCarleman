# T213 — 原控制载荷的真实局部能量配对

固定基线 `9a2857abc4c61b3c6de1fa2d282bac81f14a3d16`；三模块九声明。原文 `paper/main.tex:2338–2415` 的同一能量解与原有界势，AUXILIARY、17/26。

真实时间乘子与固定连续线性值/梯度算子的 Bochner 延拓交换。可测时间集合 s 的实际截断 W=1_s 在 L² 类上幂等，其真实内积等于 s 上积分；截断一侧或两侧的配对相同。对原有界标量乘子 b，局部势配对精确等于 b 作用在同一截断态上的二次配对。这些均由实际 a.e. 代表证明，不读取零测端点。

实际 Bochner→产品 L² 等距映射 J 与时间截断交换为 J(WY)=1_(s×Ω) JY。证明先在真实简单函数上使用可测 piecewise 截断与原产品代表，处理零 Lp 类的 a.e. 代表，再由真实简单函数稠密性与两边连续线性映射延拓。没有假设 J 满射或任意 Bochner 代表逐点可测。

将上述身份接入实际 dirichletTimeLoad=E*U−G*GY−E*J*bJEY，得到完整局部配对：〈D,WY〉=〈WU,WEY〉−‖WGY‖²−〈b JWEY,JWEY〉。所有对象与原同一 b/Y/U 一致，原梯度耗散项符号与系数保留。真实 b.map 的原算子界、Cauchy–Schwarz 与 J 等距给 〈D,WY〉+‖WGY‖²≤‖WU‖‖WEY‖+b.bound‖WEY‖²；没有局部势光滑性或新的上界前提。

最后对每个 t∈[0,T] 取 s=(0,t]，T212 的真实能量等式给任意同一连续代表 q 的原局部能量不等式，保留 2 倍梯度积分和原 b.bound、控制项。Ioc 部分区间积分通过真正的限制测度等式识别；固定 T>0，不声称此步骤给新的 T 统一控制常数。本批尚未使用 Grönwall 或声称弱解唯一性；它提供后续零数据论证需要的实际局部界。

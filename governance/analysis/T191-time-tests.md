# T191 — 原时间测试取样、差商与有限张量的强一致性

数学基线为已独立验收的 T190：`f0ab18741c799cd2d821174cfce77ffbb454fa20`。原稿 `sec:control-consistency`（`paper/main.tex:2926–2956`）使用有限张量和 φ(t,x)=Σηₗ(t)ψₗ(x)，在每个原时间胞元使用左端点 ηₗ(tᵢ)，差商则为 (ηₗ(tᵢ₊₁)−ηₗ(tᵢ))/dt。本批清偿这个测试族的时间部分，空间插值收敛继续单独证明。

`timeCell_derivative_average` 从真实微积分基本定理得到每个胞元的精确身份：dt⁻¹∫η′=dt⁻¹(η(tᵢ₊₁)−η(tᵢ))。输入仅要求闭区间内的 `HasDerivWithinAt` 和导数 L² 可积；端点按区间内导数处理，不要求测试函数在区间外连续可微。证明核实每个胞元在 [0,T] 内、导数限制可积和胞元积分与区间积分的一致性。随后处理 Lp 代表 a.e. 身份，把真实差商严格等同于原固定时间胞元等距及其真实伴随的正交平均。T184 已接受的原平均强收敛立即给差商强收敛；不输入差商收敛、不使用点态代表上的形式相等。

`time_test_left_sample_error` 对只在 [0,T] 上 C-Lipschitz 的任意 L² 标量测试证明实际 L² 误差不超过 C·dt·√T。证明使用原胞元上的真实距离界，并保留有限胞元误差公式中的未覆盖区域；原时间胞元精确覆盖 (0,T]，所以这一项确实为零。不是假设某个未覆盖区为零测集。常数 C 来自测试函数，在全部时间网格之前固定，T 因子准确保留。实际前一时间层取样因此随 dt→0 强收敛。

对区间上 C¹ 测试，紧性和真实导数均值定理内部给出同一个局部 Lipschitz 常数；紧性也供应测试和导数的 MemLp。`smooth_time_test_consistency` 因而只输入 η、η′ 在 [0,T] 连续以及区间内的真实导数关系，同时输出取样和差商两个强极限。这里 C¹ 已足够，原 C∞([0,T]) 当然包含于该接口；没有添加全实轴光滑、有界或全局 Lipschitz 条件。

`timeTensor` 是真正的连续双线性映射 (v,f)↦[t↦f(t)·v]，由标量乘法连续线性映射及 `compLpL₂` 构造。实际 a.e. 代表、与原时间重构的严格交换以及两个因子同时强收敛时的强收敛均已证明。H 可为任意实赋范空间，因而同时适用于原 H、真实 H¹₀ 载体及弱梯度值空间；没有选取任意 Hilbert 空间同构。

最终 `finite_tensor_time_test_consistency` 对原任意有限张量和给两个真正 Bochner 极限：原左端点重构趋于 Σηₗvₗ；原整个有限和的差商重构趋于 Ση′ₗvₗ。空间因子允许随 n 改变，**明确输入** vₗ,n→vₗ；这还不是对原 I_h 的空间一致性定理。证明使用真实时间重构保有限和、连续双线性映射和标量代数，没有用空间极限与时间极限的迭代交换。只要求空间因子和 dt 各自收敛，无 h/dt 条件、网格嵌套或额外一致性预算。

`finite_tensor_test_endpoint_consistency` 对每个固定 τ 证明 Σηₗ(τ)vₗ,n→Σηₗ(τ)vₗ，特别包括原 0、T；它使用同一明确的空间逼近输入，不声称状态端点已经识别。

# T181 / C197：全 P1 空间的任意 L² 初值强一致性

对照原稿 `eq:conv-data-fe` 和附录 `eq:conv-data-consistency`，两模块五声明；AUXILIARY，17/26。原稿不变。

首先在真实原域限制Lebesgue L²中证明原紧支撑光滑测试函数的值域稠密。实际测试函数的加法与数乘把其H¹ jet span还原为单个测试；映到L²后，通过原分布测试分离定理证明正交补为零，再用Hilbert空间闭包得到真实稠密性。没有假设待证逼近空间稠密。

对全空间Lipschitz函数，用真实局部仿射节点插值和单元直径给点值误差≤2C h。全网格的a.e.分割、真实nodalLp代表和Lp范数界给其实际L²误差。对紧支撑光滑φ，内部获得全局Lipschitz常数；其支撑在原开域内使边界节点值为零，已证真实Dirichlet节点成员资格把插值放入**完整**conformingSpace，而非替换成一个较小抽象节点空间。

实际正交投影的最佳逼近把插值误差转给原Π_h；引入真实子空间包含等距E，其Hilbert伴随就是原orthogonalProjectionOnto。每个测试数据的误差随真实maxDiameter→0，应用T180已证的残差收缩和稠密推广，得到任意原u∈L²的强收敛Π_hu→u。

最终量化固定开凸域、有限Lebesgue测度、任意变化有限指标网格、FaceMatching和BoundaryFitted及maxDiameter→0。没有额外形状正则/局部分级/维数≤3/嵌套网格条件，因零阶L²最佳逼近本身不需要它们；原论文全部P1网格包含在该范围。没有给初值增加H¹、H²或连续代表条件，也没有将投影强收敛作为前提。E_h=R_h为实际包含，输出正是原数据一致性。

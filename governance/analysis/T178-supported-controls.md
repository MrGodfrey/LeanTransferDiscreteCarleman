# T178 / C194：实际控制支撑与弱极限的区域控制恢复

四模块十八声明，对照原 control-convergence 段落的 ω_sharp 紧包含活动区、重构控制在 ω 外为零及弱极限是区域控制零延拓的步骤。

CartesianCellControlSupport 从真实对偶开盒及 Euclidean 距离证明单元点到中心≤d*h（各方向步长≤h）。closure(ω_sharp)紧且包含开集ω给实际正厚化间隔ε，取h0=ε/(d+1)，在所有网格、时间步和控制之前固定。原节点在ω_sharp时，整个真实对偶单元都在ω内。对实际K_h=E_hB_h展开指示和，非活动节点系数为零、活动单元包含ω，证明重构在ω外a.e.为零。没有只以中心位于ω代替整个单元的支撑证明。

SupportedRegionSpace 把真实空间支撑定义为区域补集限制CLM的核，证明它闭且等价于原a.e.零支撑。任何其中的原L²函数，先限制到ω再真实零延拓，严格恢复原函数；无需ω边界零测或光滑。

BochnerKernelSpace 将连续线性映射逐时作用的真实compLpL之核构造成闭Bochner子空间，证明成员资格等价于a.e.逐时核条件。实际时间指示重构保留逐值核。统一有界序列可在此闭子空间中提取原完整弱子列并保持成本；此外任意给定的完整弱收敛序列之极限也仍在该核，并非只对某个特选子列声称支撑保留。

SupportedTimeControl 把上述事实用于实际Cartesian控制，证明同一h0对所有时间网格和控制均给原空间支撑。对任意有支撑的Bochner L²函数，实际区域限制与零延拓逐时作用给区域控制v，零延拓严格恢复原函数且范数完全相等。最后将闭子空间弱抽取与该恢复组合：原有界且支持于ω的重构序列有严格递增弱子列，其极限是实际L²(time;L²(ω))控制的零延拓，且原成本界不增。

最后这条抽取明确以已有支撑和统一成本为输入；本批没有声称离散控制存在性选择、数据/势强一致性、状态紧性、连续PDE或终态零值已完成。原活动区假设本身来自论文，无新增边界正则性。AUXILIARY，17/26。

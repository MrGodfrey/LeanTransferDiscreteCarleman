# T105：原 FD 节点观察与真实重构区域界

对应 `eq:observationinterface`、原 Cartesian 控制空间定义及附录 B Step 3 的最后一步。观察区域满足原紧包含 `closure ω₀ ⊆ ω`，ω 开、ω₀ 可测且闭包紧。

`CartesianObservationLocalization` 使用实际帽函数支撑包含有限闭节点星。非零帽函数意味着节点与当前点属于同一真实 Kuhn 单元，故距离 ≤d h。紧包含给真实正缓冲半径 r；取 h₀=r/(d+1)，则任何对 ω₀ 上重构有贡献的内部节点都在 ω 内。因此限制节点值再零延拓后的重构与原重构在整个 ω₀ 上逐点相同，阈值先于全部网格与状态。

`CartesianNodalControl` 明确定义原观察节点子类型、节点限制 B* 和零延拓 B。限制后延拓正是节点指示乘子，延拓后限制是恒等。用有限和换元证明原物理配对 `(Bv,f)_X=(v,B*f)_U`；物理权均为 ∏δ_j。控制加权平方范数仅对 ω 内实际节点求和，严格等于零延拓节点向量的原加权节点能量。

`AllowedCartesianObservation` 将上述逐点相等转成实际 L² 区域指示乘子的相等，再用真实观察范数≤全域范数和已验收的全允许权质量估计，得到

`‖σ R_h f‖_(L²(ω₀)) ≤ C ‖B* f‖_(U_h,σ)`。

右侧在 Lean 中明确为真实观察节点平方和的平方根，不是全节点范数，也没有把限制节点空间换成较小状态族。C、h₀在所有网格、时间权、τ、时间、两符号和完整离散状态之前选择。空间小条件 h≤h₀ 可由原 qmax≥1 以及 h qmax≤min(h₀,1) 内部统一；原 h qmax 小条件同时蕴含使用的 h q(t)≤1。没有增加原假设之外的间隙或网格局部性前提。

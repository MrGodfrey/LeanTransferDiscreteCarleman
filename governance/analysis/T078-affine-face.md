# T078：真实面迹的线性结构与闭面仿射核校正

七模块41声明，AUXILIARY。完成原 B.1 证明中单位立方体的有限维面迹核校正步骤；尚未与原全部 H² 逼近、原零迹及物理尺寸统一缩放组成完整 B.1。

`FaceTraceLinearity` 对真实乘积 L² 数据构造端点迹线性映射。先从平方可积 Fubini 获得 a.e. 切片 L²，再用实际区间有界系数证明端点积分密度可积，之后才拆分 Bochner 积分；加法及数乘均通过 Lp 的 a.e. 代表身份证明。适用一般 SFinite 横向测度，不偷加横向有限测度条件。

`CoordinateBoxTraceLinearMap` 将原保测度传输与端点迹组成原欧氏长方体的真实面迹线性映射，并将全部 H¹ jet 映入实际面 L² 类。其值与 T077 的实际迹逐字定义一致。

`AffineBoxTraceMap` 用 ℝ×(E→Lℝℝ) 表示仿射系数，值为 c+A(x)。在原长方体上构造实际多项式 L² 值类、其真实常弱导数类及真正面迹线性映射。面迹通过 T077 的连续代表定理识别为多项式在原面上的实际限制。仿射系数参数覆盖所有仿射多项式，未限制斜率或边界模式。

`ClosedCoordinateFaces` 证明任意正边长开长方体的闭包是对应闭长方体，并将第 i 个上下闭面精确识别为横向闭长方体的 insertNth 像。这包括闭面边缘及角点，亦包括横向维数零。体积及迹仍在开横截面上定义，不把面边缘的任意 Lp 值当作迹。

`FiniteKernelCorrection` 对任意有限维实赋范空间和实际线性映射 L，证明存在 C>0，使每个 p 都有 q∈ker L 且 ||p−q||≤C||Lp||。证明在实际有限维 range 上使用开映射定理得到有界原像，再取 q=p−r；不假定待证范数等价。对任意有限映射族取正的有限总上界，得到统一 C，包含空指标族和零映射。

`AffineBoundaryKernel` 将面迹为零精确等价于多项式在整个闭面处处为零：先用正测开集上的连续 a.e. 唯一性，随后延拓到闭包。对任意面集合 J，构造实际全部面 L² 类的有限乘积映射，未选中的面分量设零。其核严格等于在 J 的每个闭面上消失的仿射多项式空间。所有 J 构成有限族，故对一个固定长方体可取统一核校正常数。有限乘积范数为 max 范数，另直接证明其不超过所选面 L² 范数平方和的平方根。

`AffineBoundaryCorrection` 用所有已证真实弱坐标导数组装仿射多项式的真正 H¹ jet，识别其原 L² 值与完整欧氏梯度；通过有限维连续映射界将系数校正转为实际 bulk H¹ 误差，得到

`||p−q||_{L²(B)} + ||∇(p−q)||_{L²(B)} ≤ C (Σ_{F∈J} ||Tr_F p||²)^(1/2)`，

其中 q 在每个所选闭面上处处为零。单位立方体专门定理在任意维数 d+1 和任意面集合 J 上成立；C 仅依赖维数，J 不影响 C。固定一般盒子的中间常数可能依赖端点 a、b，不能据此宣称原物理网格统一缩放。原证明使用的正交补和最小化器已由等价的有界原像校正路线替代，最终核归属与误差界保持。

下一步须将此校正和 T074 原全部 H² 仿射逼近通过实际零迹及迹线性身份组合，并证明随网格侧长可比性统一的 h² 尺度；原 H¹₀ 与物理面零迹接口、两非平行面核为零及 B2 仍待。原完整 B.1/B.2/P1 未被本阶段单独证明；原文计数保持12/26。

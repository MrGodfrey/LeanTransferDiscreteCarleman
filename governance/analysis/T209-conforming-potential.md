# T209 — 原时间平均势与实际 P1 有限测试一致性

基线 `7d343224295439a2c5b91f1128facfc9b42feafd`。两模块十一声明；原文 `paper/main.tex:2389–2398` 中原 P1 物理测试及势项极限的接口。AUXILIARY、17/26。

`fixedTimeCellPotential` 是同一原产品势 b 在每个真实时间胞元上的平均，固定 T 的传输只识别相同时间测度。value 定理明示 dt⁻¹∫胞元 b，bound 精确等于 b.bound。`time_average_product_potential` 与固定 T 版本证明：先以实际逐步平均势乘真实 L² 空间状态、再构造 Bochner 时间重构并映到产品空间，恰等于同一时间重构的产品像乘原重构平均势。证明在实际 a.e. 类中逐胞元识别，使用互不相交真实时间胞元及真实乘子 map_ae，不要求该乘子与 Galerkin 投影交换。

`time_average_reconstructed_weak_pairing` 接上述精确身份、实际 Bochner 产品等距映射的弱连续性以及先前证明的原时间平均势强收敛。对于原状态重构的统一界/弱极限及趋于真实有界产品测试的测试重构，原实际平均势配对趋于同一 b 乘同一状态极限的配对。此为通用极限接口，尚未宣称任意离散控制序列自动具有所需极限。

`p1FiniteTestSequence` 是原 full P1 Galerkin 子空间中所有 N+1 物理节点的有限测试和，系数为 η_l(t_k)，空间测试为实际节点插值。lift 和 value 身份明确它与原 Dirichlet 插值和真实 nodalLp 的关系。

端点一致性对任意固定 η_l(0)、η_l(T) 保留真实时间 0/T，内部由节点插值 L² 强收敛推出两端点，不要求 η 在端点为零。只需 maxDiameter→0；不需形状预算或时间导数。

时间一致性从既有真实 H¹₀ 有限测试收敛得到三项结论：前层测试值重构、后减前除 dt 的真实差分重构、前层测试真实梯度重构，分别趋于原有限光滑测试、其时间导数和空间梯度。其前提为原统一形状正则/匹配/边界拟合、maxDiameter→0、dt→0 与固定 T，允许空间自由度随 n 变化。差分符号、i.castSucc/i.succ、全部空间梯度和原 consistent L² 质量保持；不引入 h 与 dt 的耦合。使用完整 P1 子空间实际节点测试，未将整个状态空间替换为较小节点空间。

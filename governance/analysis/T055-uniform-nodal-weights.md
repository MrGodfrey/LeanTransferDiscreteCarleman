# T055：原四类权的节点权构造与全域节点测试

四模块16声明，AUXILIARY。原文保持12/26。构造真正以几何顶点为自变量的共享节点权，对原四类允许权提供同一网格无关δ、原阈值以内有效θ和实际比较，并证明零边界节点测试的H¹₀一致P1成员及全域质量强制性。尚未证明完整H¹一致P1空间的节点表示，或实际全域加权投影稳定性。

给定正单元权a_i，对几何点x取所有以x为顶点的实际单元索引。该集合有限；非空时取a的最小值，空时取1。这不是按每个单元分别定义的多值权；相同几何顶点只有一个值。若共享顶点的单元满足a_i≤θa_j，θ>0，则对每个K_i顶点有a_i/θ≤ω≤a_i，局部任意两节点权比≤θ。证明直接使用真实共享顶点，未引入扩大为θ²的局部比例。

原权的单元样本定义为σ在该单元0号顶点的实际值，再乘原分片因子1或ℓ_i⁻¹；σ=q^τ exp(ηqρ)，η绝对值为1。由于分片逆尺度在共享边界可能求和，样本刻意使用明确的单元因子，不把实际边界点的分片求和值当作所属各单元值。gradedWeight与单元因子的身份仅按已证的单元a.e.身份使用。

单元样本正性由真实指数权正性和ℓ_i>0给出。对真实相邻单元的任意点，Lipschitz profile与距离≤2h给实际γexp(2Lhq)比较。应用于两个顶点得到样本间同一比例；应用于同单元的任意点及样本顶点得到实际|ζ(x)|与样本a_i的双向比较，使用a.e.分片身份后包括四类实际权。

固定profile、原1≤γ<Γ_d后，内部选L及δ≤1，θ=(γ+Γ_d)/2满足1≤θ<Γ_d。δ先于网格、尺度、时间权、τ、时刻、符号及是否乘ℓ⁻¹。hqmax≤δ统一给样本分级≤θ，从而构造正节点权，a_i/θ≤ω节点≤a_i，且单元a.e.有|ζ|≤θa_i与a_i≤θ|ζ|。这明确使用有效θ，不混用原meshγ。

任意节点数据f在边界节点为0时，ω²f仍在边界节点为0。因此真实nodalLp(ω²f)属于已构造的H¹₀一致P1空间；不要求任意点值函数ω本身是连续或可测，因为插值仅使用有限节点值。这里没有对L²等价类作点值操作。

对任意正a和邻接分级1≤γ，以a_i/γ作各单元的正归一化；已有节点范围恰满足局部系数强制性。真实节点函数在每个单元等于真实局部多项式，且节点函数属于L²。实际L²乘积可积，真实网格分片积分逐项求和，给μ(d,γ)乘加权节点系数能量的全域质量积分下界，再准确识别为真实L²内积。

该最后结论针对实际节点插值状态与其节点平方加权测试。尚未将任意完整V_h状态替换成这种节点状态；全空间表示、加权状态/测试范数比较及最终正交投影估计仍待。上述积分下界本身只需γ≥1；要称正强制性时须接入已证明的有效θ<Γ_d及非零能量。

# T099：原弱刚度的精确坐标边组装

三模块13声明，AUXILIARY。对原全部内部节点状态f、g、全部正步长和原有限网格，把T098原Dirichlet形式的真实单元差商和精确重排为

`a(R_h f,R_h g) = (∏ δ_j) Σ_(z∈∏Fin N_j) Σ_r D_r f(z) D_r g(z)`，

其中D_r是原实际物理节点数据的真实坐标前向差商，零边界数据来自原cartesianInteriorData。上式同时给原WeakSobolevJet弱梯度配对和同一boundedDirichletOriginalForm.scalarForm版本。这里z_r从0到N_r−1，横向坐标0的项为零，横向N_r的边也为零，因此完整非零物理边及两端边界轴向边均包含。

`FiniteCartesianShift` 证明一般有限矩形格网上的整坐标+1掩码平移：若F在所有被移动坐标的0和N_j面上消失，则原有限和不变。证明用每个Fin(N_j)的真实循环旋转组合成Pi等价。出现末点回绕时，平移后的N_j面和旋转后的0面两项都严格为零；无回绕时两个真实整数点严格相等。空索引情形也保留，没有假设一个未验证的坐标边重数。

`CartesianLatticeDifferences` 将原有限节点数据放回实际整数格点，证明原物理边界面的零值；定义真实坐标后继和前向差商。任一横向坐标位于0或N_j面时，差商两端都位于该原边界面，因此整个差商为零。真实Kuhn相邻顶点整数索引的后继恒等式把原单元差商精确识别为同一坐标前向差商。

`CartesianKuhnEdgeAssembly` 对每个固定π,k，Kuhn前缀只平移横向集合J={j|(π⁻¹j)<k}，不平移轴r=πk；前述真实横向零值清偿一般有限和重排的全部边界条件。对k再求和并用π等价换元，得到与π无关的原坐标边和。实际单元体积对格点平移不变，所以可以从该固定π的格点和提出；全部π的实际体积总和严格为∏δ_j（T089已有证明）。这样精确完成原证明的边贡献组装，无需新增“每排列体积相同”或“每边d!重数”的假设。

最终恒等式使用原Dirichlet scalarForm及全部原真实弱H¹₀重构；没有另定义替代能量，没有只讨论二次型，f和g独立。该等价组合路线保留原最终刚度结论所需全部边权，包括物理边界层与角点。原标准2d+1点Laplacian的离散分部求和仍待，因此完整eq:fdstiffness和FD/P012尚不提升。原文14/26，原稿与工具链未改。

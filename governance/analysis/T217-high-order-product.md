# T217 — 任意阶实际弱乘法与 H₀ᵐ 保持

固定基线 `17b0a22b45b9d314f90414b72d3c3198ef129f0d`。原稿 `paper/main.tex:2615–2652` 中光滑权保持 V 和 D(A) 的空间部分；两模块11声明（9定理、2定义）。AUXILIARY、17/26。

现有全阶 Leibniz 场已经由真实分布乘积规则逐阶求导。本批通过置换归纳证明该场的对称性：cons 情形使用原弱导数唯一性，swap 情形使用真实混合弱导数交换，所有调用都核对剩余阶数，未把对称性或乘积射流存在作为输入。对每个对称多重指标组装这些真实 L² 场，证明新射流满足所有原分布导数关系，空指标恰是原乘积。

每个坐标词场由原连续分量映射取得；每项 Leibniz 场是有限个真实有界乘子的连续线性作用之和。有限分量组装得到真正连续 Hⁿ→Hⁿ 的乘法算子，无额外目标范数估计前提。这里 Hⁿ 采用已证明完备并与原 Sobolev Hilbert 范数等价的图拓扑。

在原域上，该乘法作用于任意原紧支光滑测试时，所得射流恰为实际函数乘积测试的全阶射流。由连续映射保持测试闭包，得到 H₀ⁿ 保持。最终对任意真实 boundedSmoothOn 的乘子，使用实际内部 Fréchet 导数构造其全部系数，从任意 Hⁿ 或 H₀ⁿ 原状态内部构造乘后状态；最后给任意 Hⁿ∩H₀ᵐ 的保持（取n=2m即原算子域空间）。

没有假设 Ω 外存在光滑延拓，也没有用点态边界值代替原闭包条件。原权的 smooth 假设在此正常保留；本阶段没有把一般 W^{2m,∞} 算子系数假定为光滑，尚未宣布其弱乘积或完整 Prop A.1。

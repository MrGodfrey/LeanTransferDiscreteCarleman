# T075：全部弱区间 H¹ 类的实际迹与乘积端点积分

五模块25声明，AUXILIARY。为 Appendix B 物理面校正构造实际弱迹基础；尚未把完整空间弱测试转换成所有实际坐标切片身份，因此本阶段不宣称长方体空间迹定理或 B1 完成。

`WeakIntervalRepresentative` 对任意 Hilbert 空间 H 和任意实际 L² 类 u、du，从所有紧支光滑测试的原向量弱导数身份，证明存在闭区间上的连续代表。取 du 的真实 Bochner 原函数 F，证明 u−F 的弱导数为零；已证的分布常数引理给 u−F a.e. 为常量，从而 U=c+F 是所需代表。闭区间连续代表的唯一性包括两个端点，由正长度区间 Lebesgue a.e. 相等推出。`TimeGrid` 仅复用任意正区间长度 L=period 的已有测度接口，不引入周期端点相等条件，也无步数或时间方向限制。

`WeakIntervalTrace` 在全部真实弱 H¹ 图子空间 `(u,du)` 上选取上述唯一连续路径，证明其实际 `pathL2` 正好还原原 u。由代表唯一性得到加法与数乘相容，再用已证迹估计构造到 C([0,L];H) 的有界线性算子。所有 t∈[0,L] 都有

`||Trace_t(u,du)|| ≤ (sqrt L/L)||u|| + sqrt L||du||`。

图空间使用 L²×L² 的 max 范数；路径算子的上界为 sqrt L/L+sqrt L。这是正确的区间长度依赖，不宣称 L 一致。实际任意两点迹差等于原 du 的 Bochner 积分。全过程没有给原 L² 类附加连续代表前提，选择函数也不改变实际值类或迹的唯一性。

`ScalarIntervalTrace` 对实际标量弱 H¹ 图使用原函数给出的绝对连续性和 a.e. 强导数身份，通过真实积分分部证明

`∫₀ᴸ[u(t)+(t−c)du(t)]dt = (L−c)Trace_L + c Trace_0`。

因此 c=L、c=0 的积分除以 L 分别精确等于左、右端点迹；适用于原全部弱类，无经典逐点导数前提。

`FiberEndpointIntegral` 在真实乘积测度 μ×Lebesgue|(0,L) 上定义

`E_c(f,v)(x)=L⁻¹∫₀ᴸ[f(x,t)+(t−c)v(x,t)]dt`。

证明它对乘积 a.e. 代表不变，并对 0≤c≤L、任意乘积 L² 数据有真实 L² 成员资格和

`||E_c(f,v)||² ≤ (2/L)||f||² + 2L||v||²`。

先证明有界系数乘 v 的实际 L² 可积性，再用真实产品平均的 Cauchy–Schwarz/Fubini 及平方三角界；没有用不可积积分的默认零值形成伪估计。μ 只要求 SFinite，不要求有限总质量。

`WeakSliceEndpointTrace` 证明若实际切片满足完整一维弱导数身份，则上述两个端点积分正好等于该切片唯一连续代表的端点。真实乘积 L² 条件通过 Fubini 供应 a.e. 切片 L² 资格；对 a.e. 切片构造真正弱图并识别原函数与原导数。最终得到 a.e. x 的连续代表、完整弱身份和两端点精确等式。

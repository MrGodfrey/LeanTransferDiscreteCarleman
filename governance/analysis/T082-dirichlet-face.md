# T082：全局 H¹₀ 到局部物理盒零迹与全 H² 局部逼近

四模块16声明，AUXILIARY。为原 B.2 应用 B.1 供应实际局部零迹条件，不新增或假设一个边界迹定理。

`SubdomainContinuity` 对任意 T⊆S 证明实际 L² 限制的范数不增及线性性，构造连续线性限制算子。原完整 WeakSobolevJet 的每个真实字段同时限制，保留全部弱测试身份；其原有限乘积图范数不增，故限制在真实 H^m 图拓扑中连续。对全局紧支撑光滑测试，局部值类 a.e. 等于同一个实际函数，没有改为任意代表。

`CoordinateBoxTraceContinuity` 从 T077 的实际平方迹界及真实 value/field 连续线性映射的界，证明实际盒面迹对原完整 H¹ 图范数有界；打包为与既有弱面迹逐项相同的连续线性映射。此处只需固定盒子的连续性，常数可依赖该盒，未冒充 B.1 的网格统一常数。

`DirichletBoxFace` 将局部 H¹ 限制与真正面迹复合成全局 H¹ 上的连续线性映射。若局部整个闭面位于 Sᶜ，每个原全局 SpatialTest 的支撑包含于 S，故其实际函数在该面为零。利用已验收的连续代表面迹识别及真实横向限制测度，证明这些测试的局部迹类为零。连续线性映射的核闭，因而包含所有测试的线性张成及其完整 H¹ 图闭包，即原 `dirichletJetSpace S`。得到任意原全局 H¹₀ 状态限制到局部盒后该面的真正弱迹为零；无需对原状态假设连续代表。

`DirichletLocalAffine` 证明真实弱 jet 限制与低阶截断交换。对任意开域 S、任意原全部 H² jet 且原值属于 `dirichletSubspace S`，由原弱导数唯一性将其一阶截断识别为原 H¹₀ 状态。局部所选闭面包含于 frontier S，S 开使这些面在 Sᶜ，因此前一模块内部供应 B.1 的所有局部零迹。最终调用原 B.1，得到实际局部仿射 p、真实 H¹ 残差，p在整个所选物理面上零，并且

`||u−p||_{L²(B)}+h||∇(u−p)||_{L²(B)} ≤ Ch²||D²u||_{L²(B)}`。

右端为原全局 Hessian 字段的实际 L² 限制范数，左端残差的值类 a.e. 等于原全局值代表减 p。常数来自 B.1，位于 S、局部盒、h、面集、原状态之前，仍仅依赖维数与侧长比较界。局部零迹不是最终输入；全局 H¹₀ 与面属于物理边界是原 B.2 的实际条件。

本批仍未构造原 FD Kuhn 网格的节点星、矩算子和局部重构，也未完成加权有限重叠求和。因此 B.2/P1/FD 均保持未完成；只完成从原全局状态到原 B.1 局部边界条件及局部逼近的桥接。

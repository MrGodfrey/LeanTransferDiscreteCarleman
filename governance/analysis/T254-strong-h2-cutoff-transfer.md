# T254 / C270: actual full H² continuity of boundary cutoff transfer

Auxiliary to original Corollary A.2, paper/main.tex:2659–2665; coverage stays 18/26. This stage transfers actual strong zero-boundary approximation from a box through a fixed boundary cutoff. It does not yet construct the boxes/charts needed to cover the original curved domain.

The source is precisely H²∩H¹₀: dirichletH2JetSpace is the inverse image of the genuine closed H¹ test closure under the actual H²-to-H¹ truncation. The proved truncation norm bound yields a CLM, so this is a closed subspace of the complete full H² graph space and is itself Banach. It is not H²₀ and imposes no zero first-derivative boundary condition. Its actual scalar value projection is continuous.

A continuous scalar value map from that source, whose values are genuinely realized by target H² jets on an open domain, lifts linearly by weak derivative uniqueness. Its graph equals the closed actual value equality set. The Banach closed-graph theorem gives continuity in the full source/target H² norms. This only gives continuity for a fixed map; no uniform norm across domains/cutoffs is inferred.

For a compact global smooth cutoff η and open domains S,T agreeing on its full support in both directions, the scalar map is actual multiplication by η after L² zero extension from S and restriction to T. It is a true CLM because zero extension is the adjoint of actual L² restriction. Target H² membership is not assumed for that output: the source H² jet internally supplies its true negativeLaplacian; its H¹ truncation is in the genuine source H¹₀. T242's actual cutoff weak equation, including all first/second cutoff terms, and its actual target H¹₀ preservation provide a target weak Poisson state. The stated target regularity then supplies its H² lift.

The generic DirichletH2Regular target property is explicit and only asserts regularity for each already given H¹₀ weak solution, not all-load solvability or any bound. It is proved here for each original positive-side-length box, both actual globally smooth graph sides under the actual height/slope bounds, and every nonempty original exponential smooth inner domain. These instances use the already established original weak regularity theorems without adding a new axiom or a target Hessian hypothesis. The final generic transport theorem retains that property as a visible input, to be supplied by these concrete instances in applications.

The resulting cutoffH2Transfer has the exact actual value, AE indicator formula, original full H¹ truncation, true H¹₀ membership and full H² strong continuity. When the source value is an actual global smooth φ, target weak-jet uniqueness identifies the entire result with the actual global smooth product ηφ restricted to T, not merely its zeroth field. The source AE identity is converted to a conditional whole-space AE identity before restriction to T; support agreement is used exactly when η is nonzero.

Boundary values are also actual: on the open set {η≠0}, S and T agree. The genuine frontier-inter-open identity therefore transfers each target frontier point with η≠0 to the source frontier; where η=0 the product vanishes directly. Thus a global smooth source function vanishing on the true source frontier produces a global smooth cutoff function vanishing on the true target frontier. No unproved boundary trace characterization is used.

The final theorem starts with an arbitrary original box H²∩H¹₀ jet. It internally obtains the T253 compact smooth zero-boundary sequence, applies the actual fixed cutoff map, identifies every image with the global smooth product, proves every image has true target frontier zero and genuine target H¹₀, and obtains full H² convergence to the exact cutoff-transferred original state. It does not replace that limit by the original uncut state; doing so requires a separately proved cutoff-one/support qualification. Actual covering cutoffs, half-space/graph gluing and the weak uniform convex estimate remain pending.

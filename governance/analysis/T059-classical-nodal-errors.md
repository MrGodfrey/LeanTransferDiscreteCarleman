# T059：经典导数控制下的真实单纯形节点插值误差

三模块13声明，AUXILIARY，原文12/26不变。本阶段证明供后续σ²z超逼近使用的实际局部节点误差。仍明确要求真实经典导数及其Lipschitz界；不是原eq:p1-interpolation对于任意H²状态的完整证明。

首先，实际仿射p在半径r>0的真实内球中满足|p|≤R，R≥0，则其真实CLM导数范数≤4R/r。证明在球心和半径r/2方向点比较，使用真实仿射差商，不假设单元是参考单纯形或隐藏形状控制。即使d=0，算子范数判据也有效，不选择不存在的单位方向。

真实节点插值I满足I(f-p)=If-p。若闭单元上|f-p|≤R，则|f-If|≤2R；若某点的真实导数满足||Df-Dp||≤G，则||Df-DIf||≤G+4R/r。前者由非负重心坐标的实际凸组合得到，后者对实际仿射If-p调用内球导数界。没有对一般L²等价类作顶点取值。

构造实际一阶Taylor仿射多项式p_a(x)=f(a)+Df(a)(x-a)，证明其点值和CLM导数身份。在凸集上f处处可微且实际Df为L-Lipschitz，所有点距a≤h时，真实均值定理给|f-p_a|≤Lh²和||Df-Dp_a||≤Lh。这里只需可用的常数1，不声称最优Taylor系数1/2。

取实际单纯形顶点作锚点，若h是单元全部点对距离的上界，则|f-If|≤2Lh²。再有真实内球及h≤κr，得到||Df-DIf||≤(1+4κ)Lh。可以取h=实际直径；h≥0并未强制正，所以d=0/零直径情形也被保留。r>0确保除法合法，κ非负从形状条件内部推出。

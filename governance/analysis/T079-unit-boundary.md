# T079：参考立方体上全部弱 H² 的边界仿射逼近

四模块15声明，AUXILIARY。将 T074 的真实全弱 H² 仿射逼近、T077 的实际面迹及 T078 的闭面仿射核校正组成参考立方体上的完整边界逼近结论。原物理网格上的统一 h² 缩放仍待。

`CoordinateBoxConvexity` 内部证明任意坐标开长方体凸，所有边长为正时非空且体积严格正。单位立方体的实际欧氏距离由环境维数界控制；证明使用真实欧氏平方范数的坐标和。无外给 Poincaré 常数、几何直径或体积条件。

`AffineJetTraceIdentities` 将实际仿射 H¹ jet 组成线性映射；通过原开域的弱导数唯一性和值类识别证明加法、数乘。证明仿射 jet 的真正弱面迹严格等于已验收的实际仿射面迹映射。对单位立方体任意面给统一估计

`||Tr_F w|| ≤ 2 (||w|| + ||∇w||)`，

右端为实际 L² 值及全梯度范数。另证明两份真实 H¹ jet 相加时这些范数之和的三角界。

`UnitCubeH2Affine` 先用真实 H¹ 值注入性证明 T074 的实际残差等于原 H² jet 的一阶截断减去完整仿射 jet。再对原任意弱 H² 状态应用 T074：凸性、有界性、正体积、直径和全部弱前提均由实际单位立方体数据内部供应。得到无约束仿射逼近，正的常数先于任意状态量化，仅依赖维数。没有增加光滑代表、连续性、预先存在的逼近或额外切片假设。

`UnitCubeBoundaryAffine` 对任意面集合 J 和实际 H¹ 状态 w，使用真实迹线性性及所选面零迹证明近似仿射 p 的面迹等于残差迹的负值。有限乘积 max 范数与每个真实面的估计给面族统一控制。T078 提供的 q 在所选整个闭面上处处消失；真实 jet 线性性给

`w−q = (w−p)+(p−q)`，

三角估计因而将核校正误差与原逼近误差组合。最后将该校正应用于上一模块从全部弱 H² 状态构造出的 p，得到

`∃ C_d>0, ∀J, ∀u∈H²((0,1)^(d+1)), Tr_F u=0 (F∈J) ⇒ ∃q affine, q|_F=0 (F∈J),`

`||u−q||_{L²}+||∇(u−q)||_{L²} ≤ C_d ||D²u||_{L²}`。

零迹是原真实连续弱迹映射的零 L² 类，不是点值假设或有待证明的抽象迹接口。输出残差是原一阶截断减去真实仿射 jet，包含原全部弱导数身份。`unitCube_h2_boundary_affine_actual` 另直接返回实际仿射多项式 p、实际 H¹ 残差 r，证明 r 的值类 a.e. 等于原 u−p，并保留所有闭面条件与 Hessian 半范数界。环境维数为 d+1≥1，包含一维区间及零维横截面；常数不依赖 J 或 u。

本结论是原 B.1 的单位参考域实例。没有把固定物理盒子的常数误当成网格统一常数；尚须完整仿射缩放真实弱 H²、面迹和体积范数，并利用各侧长与 h 可比性得到原 h² 估计。原 H¹₀ 到物理面零迹接口、两非平行面核为零及 B2 也仍待。原完整 B.1/B.2/P1 保持未完成，覆盖计数12/26。

# T076：原乘积域弱导数、全部弱切片与真实 L² 面迹

五模块16声明，AUXILIARY。将 T075 中显式保留的切片弱身份从原乘积域完整 `IsWeakSpatialDerivative` 身份证明出来。

横向域 S⊆SpatialCoordinates d 为开集，volume.restrict S 有限；轴向区间 (0,L) 任意正长度。数据 f、v 是原乘积测度上的任意真实 L² 类。唯一弱正则前提为在 S×(0,L) 上、方向 (0,1) 的全部紧支光滑测试积分分部身份；没有光滑代表、连续性、单独切片身份或边界值假定。

`CountableWeakTests` 解决零测集对测试函数的依赖。对可分的实际测试对集合，取可数稠密子集，将逐测试的 a.e. 等式取可数交，再由每个切片线性配对的连续性闭包延拓到所有测试。实际测试对为 `(ψ',ψ)` 的两个 L² 类，其所在 L²×L² 空间的第二可数性来自真实区间测度可分性。没有对不可数测试直接交换 a.e. 和全称量词。标量空间弱身份与既有一维向量积分身份精确等价。

`TensorSpatialTest` 构造实际测试 Φ(x,t)=φ(x)ψ(t)，证明闭支撑在两个闭支撑的紧乘积内且包含于原域。真实 Frechet 导数在 (0,1) 上等于 φ(x)ψ'(t)，无坐标符号遗漏。

`ProductWeakMarginal` 对固定 ψ 使用上述测试。真实乘积 L² 数据与 ψ、ψ' 的 L² 拉回相乘后属于 L¹；横向有限测度是此处明确的前提。对横向 φ 乘积的可积性由实际张量测试及其导数的 L² 资格供应。Fubini 后对横向开域使用原光滑测试基本引理，得到 ψ 对应的一维弱积分身份在几乎每个 x 成立。未用默认积分零值，也未只检验有限个横向测试。

`ProductWeakSlices` 从 Fubini 给出的 a.e. 切片 L² 资格构造真实切片类，无资格的零测例外处定义为零。将上一模块的逐测试身份转换成实际 L² 内积，再用可数化引理，得到同一个满测集上所有一维测试同时成立。最后通过 a.e. 类代表一致性回到原 f(x,t)、v(x,t)。由 T075 得到 a.e. 切片的唯一连续代表、原弱导数和两端点显式积分身份。

`ProductFaceTrace` 将端点积分实现为真正的横向 L² 类，证明代表一致性以及对每个 c∈[0,L] 的

`||E_c(f,v)||² ≤ (2/L)||f||² + 2L||v||²`。

c=L 为左面，c=0 为右面；该参数是积分核的偏移，不是评价位置。对原完整乘积弱导数状态，这两个 L² 类分别 a.e. 等于切片连续代表的 U(0)、U(L)。没有选择原 L² 代表的边界点值当作迹，也没有给未证明的面函数添加成员资格。

该结论是真实乘积域单轴面迹，适用原全部弱数据。尚须把 SpatialCoordinates(d+1) 的长方体通过实际坐标拆分与乘积测度连接，并处理任意物理面集合的仿射核校正和网格统一性。原完整 B1/B2/P1 未完成，原文仍12/26。

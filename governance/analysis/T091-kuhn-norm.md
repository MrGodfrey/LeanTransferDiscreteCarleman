# T091：实际重构与载荷的网格一致无权 L² 界

五模块24声明，AUXILIARY。对原完整内部节点空间，构造原 `R_h f=∑f_aφ_a` 的真实全空间函数和原域 L² 类，证明

`(d+2)⁻¹ E(f) ≤ ‖R_h f‖² ≤ E(f)`，`‖L_h f‖² ≤ (d+2) E(f)`，

其中 `E(f)=(∏δ_j)∑f_a²` 精确为原对角物理节点质量平方范数。常数先于全部网格大小、正步长、平移和原任意离散向量；不含节点数、单元数或网格长宽比。加权全允许权族、局部 Q_h、刚度身份与完整 FD/B.2 仍待，原文保持13/26。

`CartesianKuhnReconstruction` 直接定义原帽函数有限和，证明每个真实闭单元上等于以完整内部数据零延拓为系数的实际 P1 插值。所有内部帽连续紧支，故其有限和也全空间连续紧支、真正 L²，平方真正可积。没有把离散向量当成 L² 类去取节点值。

`SimplexLoadNorm` 以已验收实际局部双对偶积分和真正可积性计算精确单元载荷均值与平方积分：若 m=|K|/(d+1)，则 `∫L_K=m∑c_i`，`∫L_K²=m((d+2)∑c_i²−(∑c_i)²)`，因而 `∫L_K²≤(d+2)m∑c_i²`。这些是实际单纯形 Lebesgue 积分，不是独立假设的多项式系数范数。

`CartesianKuhnMassAssembly` 用实际内部点单射证明任意物理点处内部数据零延拓的平方，恰等于平方数据的同一延拓；域外数据为零，也严格消去载荷活动顶点的指示条件。T089 的真实帽函数质量及实际单元积分供应 `∑_{K,k:x_k=x_a}|K|/(d+1)=∏δ_j`。有限三重和重排给任意内部数据的完整质量组装，特别是平方数据的 `∑_K(|K|/(d+1))∑_k c_{K,k}²=E(f)`，没有粗略估计网格基数。

`CartesianKuhnNormBounds` 将实际每单元重构平方积分的已证一致 P1 质量界，及新的实际载荷平方积分界，沿同一真实有限分割积分求和。重构局部下界为该单元节点质量的 `1/(d+2)`、上界为1；载荷上界为d+2。用精确质量组装后得到原物理域上的真实积分界。所有分割应用先提供同一函数的真正可积性；载荷单元公式通过已验收a.e.等式使用，共享面不重计。

`CartesianKuhnLpNorm` 构造重构实际 L² 类、证明其代表和有限帽和几乎处处相同，并将实际积分界转写为真正 L² 范数平方界。载荷直接使用 T090 已接受的同一实际右逆 L² 类，没有换用不同或抽象的提升。

本批只证明无权情形；不从其自动宣称原 `σ` 加权比较或 hq≤1 下的全允许权族界。原稿、工具链和既有声明不变，全部原 d≥1、N_j≥2及其任意离散向量均包含。

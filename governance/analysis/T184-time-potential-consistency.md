# T184 / C200：原有限元时间平均势的强 L² 一致性

对照原稿 `eq:conv-data-fe` 与 `eq:conv-potential-consistency` 的有限元部分。四模块十五声明；AUXILIARY、17/26，原稿不变。

在固定[0,T]上构造真实时间单元指示等距，实际伴随为dt归一化积分。全部真实时间单元的不交、质量、未覆盖测度为零内部证明；紧集[0,T]及实际距离≤dt供应通用单元逼近。因此对任意标量L²时间数据，实际单元平均强收敛；不要求时间网格嵌套。

完整有限元分片势使用同一原timeCellPotential：每个时间单元内等于原b^n(x)，具有真实乘积可测性和同一b.bound的a.e.界。固定时间域的版本仅进行period=T的类型运输，并证明其实际值仍是同一时间平均指示和。没有空间取样、空间平均或空间网格细化。

几乎处处空间点上，原b的时间切片可测且有界，因而属于时间L²。实际重构切片误差积分严格等于该L²数据的真实正交平均残差平方。上述时间强逼近给逐空间a.e.的切片误差趋零。原同一L∞界提供可积支配常数(2 b.bound)² T；真实Fubini及支配收敛得到整个时空L²误差平方趋零，最终得到实际分片势L²强收敛。

最后定理适用于任意有限空间测度、原任意a.e.有界可测势和固定T的任意dt→0时间网格。不要求原b处处可测/有界或连续，不把每个空间切片均良好作为前提，不添加空间几何或时空耦合条件。范数平方积分使用真实L²代表的a.e.身份；Fubini可积性由有界性在有限乘积域内部供应。

本批清偿有限元势逼近，结合T183清偿差分势逼近。完整控制收敛仍需测试逼近、状态紧性与极限PDE/端点识别；本批不宣称这些结论。全部十五声明根导入并打印完整类型、公理，固定SHA交独立Agent验收。

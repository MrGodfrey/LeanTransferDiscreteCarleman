# T161 / C177：完整盒弱周期图空间的光滑零边界稠密性

本批完成周期时间方向的图范数逼近。四模块十六项显式声明，范围 AUXILIARY；原文连续 CE 的弱状态密度环节在坐标盒上取得实际逼近序列。完整弱估计、各经典微分字段到积分的识别及一般凸多面体仍待，P024 不提升，覆盖保持 17/26。

HarmonicGraphContinuity 在任意原 CoerciveForm 的真实算子图系数上构造实际周期谐波轨道，值严格等于 cos/sin 组合。线性性由真实连续迹唯一性证明；输入图与输出周期图均为已证 Banach 空间，以实际逐点连续迹和系数极限证明闭图，再使用闭图定理得到真正的连续线性映射。不假定谐波逼近对时间导数或算子字段连续，也未换用只有值 L² 的较弱拓扑。

HarmonicStateDensity 定义实际谐波轨道的有限线性张成。全部谐波属于已证 regularTimeCore。原 frequencyGraph 是其中的真实元素；由已证周期常系数解算子，任意谐波载荷被送至同一实际频率解。线性张成归纳及完整载荷 L² 谐波稠密性，经原连续线性等价的逆映射，给全部周期图空间的谐波状态稠密性。这里只用于逼近的连续性常数可依赖 T 和频率；本批不改变 CE 的常数量词。最后给通用接口：若每个谐波系数可由使对应轨道落在子空间中的序列逼近，则该子空间在完整周期图中稠密。

DirichletSmoothTimeCore 是原 Dirichlet 模型周期图内的真实子空间，其元素存在全时空 C∞ 代表 F，严格周期于 (T,0)，对每个实时间及整个原 frontier 严格为零，并在闭时间区间每个时刻与原连续 H 迹 a.e. 相同。加法、实数乘法都由实际 Lp 代表规则证明。对于具有实际光滑 SpatialTest 代表的两个图系数，显式构造 cos/sin 与空间函数的乘积，给全时空光滑、所有时间的周期性、全部边界零值和逐时刻实际 Lp 迹身份。

BoxSmoothTimeDensity 使用 T160 对任意两个实际图系数的光滑零边界逼近，再应用真实 harmonicGraphCLM 连续性，将每个任意谐波放入上述真实子空间的闭包。有限谐波稠密性由此给完整弱周期图稠密性。最后对任意原周期图 p 取同一序列 P_n → p，并选择相应实际函数 F_n，逐项保留全时空 C∞、严格周期、全时刻全边界零值和每个闭区间时刻的实际迹身份。

收敛拓扑正是原 PeriodicGraph 的范数，包含连续 H 迹的一致范数、弱时间导数 L² 和实际算子 L²。没有输入时间方向光滑性、全时刻 D(A) 归属、有限频率假设或给定逼近序列。这里显式输出 F_n 与 P_n 的迹身份；将 P_n 的两个 Bochner 字段具体识别为 F_n 的经典 ∂t 和负 Laplacian、与实际时空积分对齐及弱 CE 极限仍在后续完成，不以此辅助结论直接提升完整 P024。

# T084：真实局部平方积分、笛卡尔块重叠与全域加权组合

三模块16声明，AUXILIARY；本批证明 B.2 最后求和步骤所需的实际积分与网格计数，原 FD 算子的局部再现／稳定性及实际网格实例接入仍待。

`L2FiniteOverlap` 定义某点属于有限可测块族的真实重数，即成员指标集合的基数。指标函数的有限和严格等于该重数乘原被积函数。原 MemLp 身份保证范数平方可积，有限和与积分交换和真实限制积分身份给两侧估计：覆盖使全域平方范数不超过局部平方范数之和；重数≤M 则局部平方范数之和≤M乘全域平方范数。适用标量及任意实内积空间值场。继而证明真实 subdomainLp 限制范数与原代表的局部 Bochner 范数一致，并给原全局 L² 类的实际限制版本。不是将全域范数估成局部范数的线性总和，常数不含单元总数。

`CartesianPatchOverlap` 定义真实各向异性笛卡尔扩张块：给原点 o、逐坐标正步长 δ、整数格点 z 与固定半径 r，开盒端点为 `o+(z−r)δ` 和 `o+(z+r+1)δ`。若点 x 属于该块，则每一整数坐标 z_j 位于以 `floor((x_j−o_j)/δ_j)` 为中心、半径 r 的整数闭区间。真正整区间与函数笛卡尔积计数给窗口基数 `(2r+1)^d`。对任意注入到“整数格点×固定有限标签”中的有限指标集，其实际块或任意子集的重数≤`(2r+1)^d card(label)`；排列标签给 `(2r+1)^d d!`。结论不依赖 δ、o、有限网格范围或所取单元个数，边界裁剪自然适用。这里尚未证明原 Kuhn 单元／节点星的索引和支撑落入这些块；该几何接入仍是显式义务。

`FinitePatchAssembly` 对原全局实际 L² 值、梯度和 Hessian 型字段，假设实际单元族覆盖、局部块族重数≤M，以及每个单元的实际局部 `V+hG≤Ch²H`，用上述平方积分得到全域

`V_global+h G_global ≤ sqrt(2M) C h² H_global`。

采用 `V²+h²G²≤(V+hG)²` 及反向二项 Cauchy 估计，因此只有明确的 sqrt(2M) 损失，无网格总数因子。原有乘权与限制交换将同一证明应用于真正乘权字段，不要求权在此步骤可微或点态下界。最后内部供应笛卡尔排列块的实际重数界，得到固定维数和半径的明确全局常数。

本批组合定理仍显式要求局部误差界和实际索引／支撑条件，不能把这些条件误认为已经实现的原 Q_h。本批未构造原 Kuhn 剖分、节点星矩算子，也未证明其仿射再现与局部稳定性；B.2/P026 和 FD/P012 不提升，原文保持13/26。

# T255 / C271: actual compactly supported weak states have strong flat-boundary approximation

Auxiliary to original Corollary A.2, paper/main.tex:2659–2665; coverage stays 18/26. This stage constructs the required covering boxes and cutoffs for arbitrary compactly supported original H²∩H¹₀ states on either coordinate half-space. It also supplies the corresponding interior/full-space approximation in positive dimension.

First, actual boundary cutoff transfer is applied from S to T and back with the same η. The input qualification is the real restricted-AE identity ηu=u. Using both actual indicator formulas, the inner restricted-AE formula is lifted to a conditional whole-space AE statement before restriction to S. At points of S where η is nonzero, actual support agreement gives membership in T; at η=0, the stated multiplier identity already forces u=0. Thus the double transfer has the same actual scalar value u, and target weak uniqueness identifies the entire returned H² jet with the original one. No uncut-limit identity is inferred merely from support agreement.

For an actual value that vanishes a.e. off K and a genuine η equal to 1 on K, the multiplier identity follows pointwise outside a single null set. A box and η satisfying both support agreements then give strong approximation of that same original state: transfer into the box using its proved regularity, take the already constructed box zero-boundary approximants, transfer back, and use the actual roundtrip identity. Every output is a global compact smooth function, has true original frontier zero values and genuine original H¹₀ membership, and converges in the full original H² graph norm. The generic local-box helper displays its box/cutoff qualifications; it does not assert their existence without geometry.

For either actual half-space {x_r>0} or {x_r<0}, all qualifications are constructed internally from an arbitrary compact K. A real ball of radius R>0 contains K; a genuine compact smooth η supported strictly inside that ball equals 1 on K. All tangential box bounds are −R,R. The normal lower bound is 0 for the upper half-space, and the normal upper bound is 0 for the lower half-space. Actual coordinate norm bounds prove that the half-space and box agree on the full support of η. The box has positive side lengths, including the normal side. K may meet or cross the boundary plane; it is not required to lie inside the open half-space.

The original weak H² regularity of both half-spaces is supplied from the prior full tangential-invariance theorem using their actual coordinate invariance. The final half-space theorem therefore has no box, cutoff, target regularity, approximating sequence or derivative convergence as extra inputs. It takes only a genuine original H²∩H¹₀ state and an actual compact K outside which its value is zero a.e. This is precisely the class needed after localizing a general boundary state. It does not impose vanishing normal derivative or H²₀.

For the full-space counterpart, actual tangential invariance supplies original weak H² regularity when d>0. An ordinary symmetric coordinate box covers the compact support with the same genuine cutoff construction. The final full-space theorem returns global compact smooth approximants converging to the same original full H² state. Its H¹₀ and d>0 hypotheses remain explicit; no unnecessary claim about d=0 or arbitrary noncompact support is made.

General curved-boundary approximation still requires actual inverse graph transport of these global smooth functions and subsequent finite localization/gluing. Those steps, the weak convex uniform estimate and the original polytope exhaustion are not claimed here.

# T253 / C269: actual box zero-boundary approximation in the full H² topology

Auxiliary to original Corollary A.2, paper/main.tex:2659–2665. Coverage stays 18/26; the new topology interface enables, but does not yet prove, the corresponding density on curved domains.

The continuous finite-coordinate assembly reconstructs every actual Euclidean L² derivative field from all its scalar multi-index components. Componentwise L² convergence therefore implies convergence of the entire derivative field. Applying this to every order in the finite jet, and using the induced subtype topology, gives convergence in the original complete Sobolev graph norm. No scalar-value-only norm or assumption of derivative convergence beyond the supplied components is substituted.

A globally compact smooth test is restricted to any original domain by the actual restrictSubdomain map on its allOrderJet. Every resulting component is exactly the actual L² class of its smooth multiTest derivative. The first and second fields are identified with the existing coordinateDerivative expressions, including the precise reversed multi-index convention and the genuine symmetry of the second Fréchet derivative. The zeroth component is the actual function L² class.

Actual component error convergence from the earlier box density theorem is converted to L² convergence using the actual representatives. Every Sym index of orders 0,1,2 is covered (including empty fibers), and finite assembly then proves full H² convergence to the same original jet. The final theorem takes any original H² jet whose H¹ truncation belongs to the genuine H¹₀ closure on the original nondegenerate coordinate box. It internally obtains global compact smooth approximants, preserves exact zero values on the whole true frontier, proves each approximant's H¹₀ membership using the actual bounded-convex smooth-boundary-zero theorem, and proves convergence in the complete H² graph topology.

No H²₀ condition, zero normal derivative, finite-dimensional projection, assumed density on general domains or changed target state is introduced. The zero-boundary smooth sequence comes from the already proved odd-reflection/Poisson/mollification box construction. Boundary localization, graph transport and finite gluing for the original curved domains remain outstanding. The original convex uniform estimate has not yet been transferred to every weak state.

# T186 / C202：原差分单元与 Kuhn 重构的一致性

对照原稿 `paper/main.tex` 附录 `eq:conv-consistency`（2893–2900 行）。四模块十项公开声明；AUXILIARY，覆盖保持17/26，原稿不变。

证明针对原内部节点的完整物理状态、真实对偶单元指示重构 E_h、同一节点数据的实际 Cartesian Kuhn 重构 R_h，以及 R_h 的真实弱梯度。得到更强的估计 ‖E_h z−R_h z‖₂≤C h‖∇R_h z‖₂。C仅依赖维数，在原点、所有坐标步长、网格节点数、h和数据之前选择；只用δ_j>0、δ_j≤h、h≥0，不要求长宽比、网格分级或非空内部节点。

几何证明先在有序参考单纯形按1/2阈值取坐标分段：单调性保证所得0/1向量确为同一个单纯形的顶点。实际仿射图将此运回原Cartesian单纯形。真实坐标中间平面是适当仿射子空间，其Lebesgue测度为零；有限交后，在每个实际单元几乎处处存在同单元顶点，各坐标距离严格小于δ_j/2。没有以外加的最近节点性质替代几何证明。

两不同整数格点不能同时满足这些严格距离。故真实E_h值恰为该最近格点的原节点值；若该格点不是内部节点，则没有内部对偶单元覆盖这个点，E_h与原零边界节点数据均为零。此身份直接包含原未覆盖边界条带，未删除条带，也未改变E_h定义。

同一单纯形上R_h是实际节点仿射插值，顶点值严格相同。实际仿射函数Lipschitz估计、距离≤d h和梯度纤维的维数范数比较给点态误差。原真实弱梯度在单元上的身份及实际分片a.e.拼合给全域结论，再由真实Lp范数单调性得到L²估计。相比原文的缩放加零迹Poincaré路线，这里直接利用Kuhn有序顶点，保留原结论且加强右端为梯度半范数；没有加入待证一致性或Poincaré前提。

# T086：真实有限 Kuhn 网格的覆盖与几乎处处分割

四模块34声明，AUXILIARY。原文 Section 6 的正步长 Cartesian/Kuhn 网格和 Appendix B 节点基函数构造需要真实网格覆盖及单元内部不交，本批直接证明这些几何事实，不增加覆盖或不交假设。原 FD/P012 与 B.2/P026 仍待帽函数、矩与实际 Q_h，原文保持13/26。

`KuhnBarycentricCoordinates` 对参考坐标 x，扩充为 `(1,x₀,…,x_(d−1),0)`，取相邻差作为 d+1 个真实权系数。有限望远镜和给总和1，逐坐标尾和精确重构 x；当 x 在单位立方体且坐标递减时全部权非负，因此 x 属于真实前缀顶点凸包。d=0 的空坐标情形也包含在证明中。

`KuhnOrderedCell` 证明真实参考闭单纯形精确等于 `{1≥x₀≥⋯≥x_(d−1)≥0}`，反向不是仅证明必要条件。构造真实物理仿射图及逆坐标公式，物理单元成员资格精确等价于每个归一化坐标处于[0,1]且按该排列递减。对任意闭格点盒中的点，用其真实归一化坐标在 OrderDual ℝ 上排序，供应一个实际排列，得到全部 d! 个闭单元覆盖该整个闭盒，包含所有相等坐标及边界情形。

`FiniteCartesianKuhnCover` 采用实际有限索引 `(∏_j Fin(N_j))×Perm(Fin d)`，内部证明其到整数格点／排列标签的注入与基数 `(∏N_j)d!`。对原点 o、逐坐标正步长 δ 和实际开矩形域 `(o,o+Nδ)` 的任意点，真实 floor 选出有效有限格点；再使用闭盒覆盖选出实际 Kuhn 单元。给出点态覆盖及体积限制下的几乎处处覆盖，并将真实索引注入供应 T085，得到这族实际完整顶点星的点态重数≤`5^d d!`。没有假设 N_j 正：零侧长导致开域为空，原论文 N_j≥2 是其特例。

`KuhnCellInterior` 首先证明一般严格半空间结论：若实际连续线性泛函在集合上≤c，且存在实际方向 v 满足 f(v)>0，则任意内点严格满足 f(x)<c；证明使用内点球内的显式正方向扰动。应用于实际坐标投影，得到单元内点严格位于其格点盒；应用于归一化坐标差，得到对应排列上的严格递减。因此两个单元若有共同内点，其整数格点必须相同；严格排序的排列也唯一（有限线性序的严格单调自映射必为恒等）。得到整个无限整数网格所有不同标签单元的内部不交，再通过具体有限标签注入得到有限网格不交。最终将真实点态覆盖、实际内部不交及已证有限单元边界零测性组合，得到真实开域中几乎处处存在唯一闭单元。

本批没有将几乎处处唯一归属宣称为闭单元两两不交；单元公共面允许相交。也没有由覆盖和内部不交直接宣称全局 P1 帽函数连续或跨面一致。帽函数的显式构造、与局部重心坐标一致、支撑、完整内部星中心对称、零阶与一阶矩、载荷提升和 Q_h 的实际局部稳定性仍需后续证明。工具链与原稿不变，常数与全网格几何无时间周期依赖。

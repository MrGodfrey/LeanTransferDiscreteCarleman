# T227 — 实 Hilbert 正有界算子平方根的收敛构造

基线 `4728609fbece53cc6afcc9013b94592eb23ee87d`；原文A1:353的正平方根形式域身份之基础。1模块14声明（12定理、2定义）；AUXILIARY，原文17/26。

mathlib当前实Hilbert连续算子没有直接可用的完整连续函数演算实例；本批不增加复Hilbert、有限维、紧性或谱分解前提，而在真实实Banach代数内直接构造平方根。

定义标量 c₀=0，c_(n+1)=(1+c_n²)/2。递推证明0≤c_n≤1、单调；单调有界极限满足c=(1+c²)/2，因此c=1。对于任意实Banach代数元素‖X‖≤1，定义P₀=0，P_(n+1)=(X+P_n²)/2。完整归纳证明‖P_n‖≤c_n，并以非交换恒等式 p²−r²=p(p−r)+(p−r)r 证明‖P_n−P_m‖≤|c_n−c_m|。不误用任意p,r交换；所需乘积范数估计均真实成立。

标量收敛于是给实际算子范数中的Cauchy列，完备性构造真实极限P，‖P‖≤1，且P=(X+P²)/2。由此直接推出(1−P)²=1−X。全过程使用实际范数极限和乘法连续性，没有输入目标平方根或平方恒等式。

对实Hilbert空间上的正收缩R，以X=1−R。原IsPositive同时包含自伴和全部向量的非负二次型。Cauchy–Schwarz及‖R‖≤1给0≤⟨Rx,x⟩≤‖x‖²；真实自伴算子的Rayleigh范数刻画给‖1−R‖≤1。P_n逐次为自伴，闭性把自伴传至P；B=1−P自伴且⟨Bx,x⟩≥0，来自‖P‖≤1。其平方恰为R。对任意正R取K=max(1,‖R‖)，先对K⁻¹R构造正根，再以sqrt(K)缩放，得到真实正有界B且B²=R。所有零算子、零空间及非可逆情形均涵盖；无非法除零。

此阶段只构造任意实Hilbert正有界算子的真实正平方根。下一步将其用于原CoerciveForm的实际A⁻¹，证明sqrt(A⁻¹)的范围恰为原V，并把其逆定义为原正自伴A^(1/2)，核对完整组合域和范数身份。尚未在此完成原无界平方根域身份，亦未声称完整P022。

# T094：原完整 Dirichlet H² 状态的实际局部仿射再现

四模块14声明，AUXILIARY。对原实际有限 Kuhn 网格和 T093 的真实裁剪矩形邻域，将已验收 B.1 的物理边界仿射逼近落实到实际 Q_h。固定维数和原步长可比界κ≥1后，存在统一 C>0，先于任意正网格、单元、h、h/κ≤δ_j≤h和原全部弱 H²∩H¹₀ 状态 u，给实际仿射 p 与实际局部弱 H¹ 残差 r，使

- p 在裁剪块的所有物理边界闭面上严格为零；
- 同一原 Q_h 对 p 的全域真实 L² 类，在整个中心闭单元 K 上逐点满足 Q_h p=p；
- r 的真实值与 u−p 在局部盒中 a.e. 相同；
- `‖r‖+h‖∇r‖≤Ch²‖D²u‖_{L²(B)}`，右侧是同一原 Hessian 的实际局部限制范数。

`CartesianInteriorVertex` 从实际整数格点位于原开域内部推导各轴0<z_j<N_j，构造完整原有限索引 `Fin(N_j−1)`；实际 Kuhn 顶点的整数坐标身份因此证明每个内部顶点确实由原内部节点索引覆盖。没有把“属于内部”转换为额外假设的节点枚举，也不遗漏首末层。

`CartesianKuhnAffineProjection` 将真正仿射函数的有界域 L² 类代入同一个原 J_h，利用 a.e. 代表身份与真实仿射矩，得到全部内部节点 J_hp=p(x_a)。重构每个单元顶点的数据：内部顶点由新枚举及真实节点数据恒等式得到 p 值；非内部顶点严格由原零延拓及该边界顶点处 p=0 得到 p 值。实际P1插值精确再现仿射函数，遂得闭单元上的 Q_hp=p。另证明原实际 J_h 与 Q_h 的减法线性性，原 L² 差代表只通过 a.e. 身份使用。

`CartesianClippedBoundary` 证明整个中心闭单元在裁剪块的闭盒中，该闭盒又在原物理域闭盒中。实际物理面集合是有限坐标面中其裁剪端点等于原物理端点者；这些完整闭面严格包含于原域 frontier。任何中心单元点若不在原开域中，至少一个坐标等于原上下端点；闭盒包含迫使该处裁剪端点也等于原端点，因此该点属于上述所选物理闭面。该论证包含角点与多重面交线，供应实际所有边界顶点的零值；不要求p在所有人工邻域面消失。

`CartesianKuhnLocalAffine` 将物理面零直接转为实际 Q_h 仿射再现，并将已验收的原 Dirichlet 局部 B.1 定理应用于上述实际块和真正物理面集合。块宽度δ_j≤b_j−a_j≤5δ_j以及h/κ≤δ_j≤h，内部给B.1所需的h/(5κ)≤b_j−a_j≤5κh。因此B.1只按维数与5κ选择的常数，仍先于所有网格、单元、h和原全部状态。全局 H¹₀ 到局部物理面零迹仍用原图闭包定理，没有假定光滑代表或额外迹资格；局部真实Hessian范数通过原限制算子的L²身份精确转写。

具体块沿用 T093 的一致加宽裁剪路线，未声称它是原最小 B_K。当前实际再现明确对 p 的全域仿射L²类，故没有从一般H²函数取节点值。之后利用局部性与减法身份处理残差；实际Q_h误差的弱梯度逆估计、允许权和全域组装仍待。完整 B.2/P026、FD/P012均不提升，原文13/26；原稿及固定工具链不变。

# T223 — 有限阶弱有界系数的完整 Leibniz 与 Sobolev 乘法

基线 `a3993a7a580ebab556f2a780ecb0ac3f81942390`；原稿 `paper/main.tex:2624–2635`。一模块9声明（5定理、3定义、1结构）；AUXILIARY、17/26。

BoundedWeakCoefficient S n 记录原有界可测系数及截至 n 阶的全部真实有界分布导数；其链条件仅在 |l|<n 时要求 D_i a_l=a_(i::l)，由所有原紧支光滑测试的积分身份表达。列表长度超过 n 的存储项无任何导数要求且不参与 ≤n 阶公式；没有把有限 W^(n,∞) 偷换为无限光滑。truncate 只缩小真实链的阶数。

在原有限测度开域上，对任意原 Hⁿ 弱射流，逐项用 T222 的真实弱系数乘积法则，得到完整 derivativeSplits 列表展开的下一阶分布身份。分裂列表保留全部重复项、交叉项和自然二项式重数，长度守恒保证每次调用的系数和状态导数都仍在 n 阶以内。

若已给同零阶乘法值的 Hⁿ 状态，则弱导数唯一性逐阶识别其全部词字段为真实展开。更进一步，使用已证弱混合导数交换及列表置换归纳，证明展开与词排序无关；由此按原 Sym 索引装配真实 Hⁿ jet，内部证明其完整弱链及零阶值等于 a_[]u。连续性由每个原词字段、实际有界乘子和有限和的连续性给出；得到完整弱 Hⁿ 图范数上的真实乘法 CLM，绝非仅赋予目标字段名义上的身份。

所得结论不要求输入乘后状态存在、不要求系数经典导数、Lipschitz代表或域外延拓。原论文有界域满足有限测度；n=0 时弱链为空而得到实际L²乘法。该阶段供应后续一般系数算子的有限 Leibniz 展开基础，未声称已经识别原关联算子的实际微分表达式或完成其严格降阶交换子界。

# T187 / C203：原状态方程的梯度预算与重构弱极限一致性

对照原稿 `eq:conv-consistency` 和控制收敛证明中由离散能量估计识别 E_h、R_h 相同弱极限的步骤。七模块二十项声明，AUXILIARY，原文覆盖保持17/26，原稿不变。

真实Bochner分片时间重构满足减法身份和逐步范数比较；period=T 的类型运输将不同时间网格放在同一真实时间L²空间。原Kuhn弱Sobolev jet也通过真实盒端点等式置于同一个固定空间域。T186的真实空间误差逐时间单元应用，得到 ‖E_h y−R_h y‖_{L²_tL²_x}≤C h‖∇R_h y‖_{L²_tL²_x}；同一C仅依赖维数，先于全部空间、时间和数据。初步辅助推论显式保留梯度统一界及R_h的弱极限，不冒称其已由方程供给。

随后对原隐式状态方程，直接与下一步状态配对，证明含全部N+1状态节点、末端、初端及非负时间跳跃平方的精确能量恒等式。有限求和实际望远镜消去中间端点。原势的算子范数界与原控制算子范数≤1给累计刚度预算；已有真实前向能量估计内部清偿所需的状态上界。预算依赖T、M、初值范数及控制的原dt加权L²成本，不依赖空间维数、网格数、A的算子范数或时空步长比。

Cartesian实例使用原完整(2d+1)点Laplacian、原对偶单元/时间单元平均势和真实节点控制零延拓；物理内积和原弱刚度身份严格等于实际弱梯度范数平方。势平均保同一M和控制零延拓保范数均由已有真实构造内部提供。时间重构的精确平方范数身份把累计刚度预算变成实际Bochner梯度界。固定T、M、初值上界Y及控制成本上界U时，统一上界为

`sqrt(Y²+U²+(1+2M) T [energyConstant(T,M)(Y+U)]²)`。

假设均为原方程和数据预算，时间稳定条件dt M≤1/2明确保留；在固定M且dt→0的原极限中该条件最终成立。该辅助结果不要求dt→0，也不要求h、dt耦合，因重构差消失仅使用h→0与真实梯度预算。允许维数零、空内部节点、任意正坐标步长和全部原离散状态。

最终 `cartesian_controlled_states_same_weak_limit` 内部使用实际受控状态方程证明统一梯度界，再从真实误差范数趋零及Hilbert内积连续性得到：若R_h的同一时间重构弱收敛到z，则原E_h重构也弱收敛到z。此最终实例不以梯度预算或重构一致性为额外假设。它允许每层原有界势在同一M预算内变化，故包含原固定b的各层平均；未将任意系数伪称为同一固定势。

仍显式输入初值/控制统一预算、真实状态方程及R_h弱收敛。本批不构造R_h弱子列，不证明测试插值、极限PDE、连续端点或零终态，因此不提升整个控制收敛的PAPER状态。全部二十项固定完整类型、原始公理工件与同SHA CI交独立Agent。

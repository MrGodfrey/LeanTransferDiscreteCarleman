# T194 — 原有限张量测试的产品 L∞ 一致性

数学基线为 T193 `3ac3635f878b0c1521032b396a2630acdcc4da46`。对应原稿 `paper/main.tex:2926–2941` 的原节点测试 `φ=Ση_l ψ_l` 及 `E_h Φ^-` 的产品 L∞ 收敛。本批直接估计实际时间重构经真实 Bochner→产品 L² 等距映射的代表，证明其与原测试之差的 `eLpNorm · ⊤` 趋零。

差分空间估计使用实际 Kuhn 网格上的 a.e. 最近顶点身份。原 E_h 在内部对偶单元等于原取样值，在未覆盖边界条带等于边界零延拓值；T193 的顶点身份保证该值始终等于同一原光滑紧支撑测试的顶点值。实际单元直径 ≤(d+1)h，故 a.e. 误差 ≤Lip(ψ)(d+1)h。这个零阶估计只需 δ_j≤h，不需原网格步长下界；它包含原可比网格。P1 的原节点函数误差 ≤2Lip(ψ)maxDiameter，再由实际 nodalLp 代表身份转入同一 L² 空间。

时间单元 `(t_i,t_{i+1}]` 在 `(0,T]` 内 a.e. 覆盖，前层取样确为 t_i。对固定有限测试，紧区间连续性、C¹ 区间内导数及空间光滑紧支撑内部供应 A_l、B_l、C_l、D_l，分别控制时间值、空间值、时间 Lipschitz 常数和空间 Lipschitz 常数。全部常数先于任意网格选取；没有把测试误差或测试强收敛作为最终定理前提。

逐项使用 `η(t_i)v−η(t)ψ = η(t_i)(v−ψ)+(η(t_i)−η(t))ψ`，得到 `Σ_l(A_l ε_l+C_l dt B_l)`。有限和的实际 Lp 代表和 Bochner 产品代表均通过 a.e. 身份核实；最终差分表达式仍是整个原 `I_h φ(t_i)` 经 E_h，最终 P1 表达式仍是整个原节点插值。未改成未经识别的分离因子近似。

原测试的产品可测性在内部证明；`eLpNorm · ⊤` 因而就是原误差的本质上确界。最终量化界为 `A h+B dt`（差分）和 `A maxDiameter+B dt`（P1），A、B≥0 且只依赖固定测试、域、维数和固定 T。两个网格尺度各自趋零，通过 ENNReal 上的夹逼得到真正 L∞ 收敛。T 固定，没有声称测试常数对任意 T 统一；C¹ 时间条件覆盖原 C∞([0,T]) 且不要求区间外延拓。

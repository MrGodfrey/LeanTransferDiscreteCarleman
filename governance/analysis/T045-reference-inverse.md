# T045：真实单纯形 L² 节点系数与参考单元逆估计

两模块15声明，AUXILIARY，对应原 Section6 P1 逆估计的固定参考单元步骤。这里的正常数可依赖固定非退化单纯形 T，但先于所有节点系数；尚未证明仿射缩放和形状正则网格族统一性，也未供应原 h⁻¹ 加权逆估计。原文12/26。

## 实际 L² 多项式和可辨识性

`SimplexNodalLp` 在真实 simplicialCell T.points 的受限 Lebesgue 测度上构造 simplexNodalInterpolant T c 的实际 Lp 类。单元紧性供应有限测度；重心系数非负且和为1给单元内 |p_c|≤‖c‖∞，直接供应 MemLp。Lp 类与该实际仿射多项式 a.e. 相等，真实节点系数到 L² 类的映射线性。

真实非退化 d-simplex 的内部非空，凸性给整个单元包含于其内部的闭包。若两个构造的 L² 类相等，实际连续仿射多项式在单元内 a.e. 相等；Lebesgue 测度的开集正性和连续性将身份提升到整个单元。只对这两个真正连续多项式在实际顶点求值，以原精确节点插值身份恢复 c=e。因此 L² 映射单射，未在任意 Lp 代表上取节点值。

固定有限维系数空间上的实际单射线性映射给反 Lipschitz 界，从而内部证明 ∃B(T)>0，∀c，‖c‖≤B(T)‖p_c‖L²(T)。目标系数控制没有作为输入。

## 实际梯度和固定参考估计

`SimplexReferenceInverse` 从每个真实重心仿射坐标的连续线性部分定义其实际导数，再有限线性组合得到节点多项式导数。真正 Fréchet 求导和有限求和规则证明对每个 x 的 HasFDerivAt 身份。

实际一阶 Euclidean derivative fiber 读取全部坐标方向一次，并构造在单元上为该固定向量的 L² 类。证明它 a.e. 恰为原节点多项式实际 fderiv 的一阶 fiber；相对于节点系数的映射也线性。有限维性给这个真实梯度映射的连续性和算子范数。与上段系数反界组合，内部选择正 C(T)，对所有节点系数 c 得

`‖gradient p_c‖L²(T) ≤ C(T) ‖p_c‖L²(T)`。

C(T) 在 c 之前，覆盖全部仿射多项式；其导数 L² 范数是真正全坐标梯度范数，并非任意能量占位。维数0和零梯度情形允许，正 C 由加1选取，不除以梯度范数。

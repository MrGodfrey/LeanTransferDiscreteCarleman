# T096：原全部 Dirichlet H² 状态的实际 Q_h 局部误差

四模块13声明，AUXILIARY。对固定正维数 d+1 与 κ≥1，在全部原网格、单元、h>0、h/κ≤δ_j≤h 和原状态之前选取 C>0，证明

`‖u-Q_hu‖_{L²(K)} + h ‖∇(u-Q_hu)‖_{L²(K)} ≤ C h² ‖D²u‖_{L²(B_K^+)}`。

u 遍历原完整弱 H² 空间且其值属于原 H¹₀ 图闭包；Q_h 是同一原 J_h 与实际有限帽和 R_h 的组合。误差由原弱 H¹ jet 的减法定义，第一项是原值的 L² 范数，第二项是完整真实弱梯度场的 L² 范数。B_K^+ 继续使用已接受的加宽裁剪矩形，常数及有限重叠仍统一。该阶段完成 B.2 证明的无权局部误差步骤；还未声明允许权及全域 B.2，原文保持13/26。

`WeakJetLocality` 证明开放子域上原值的 a.e. 相等决定整个真实限制 jet。对实际单纯形，先限制到其内部，应用原弱导数唯一性，再通过已证边界零测集恢复闭单元上的所有场。也给有限 L² 函数的测度单调性及真实 Lp 差的局部三角不等式；有限性是明确的 MemLp 前提，没有使用无穷范数 toReal 的总化行为。

`CartesianKuhnErrorLocality` 证明实际闭单元的限制测度≤真实裁剪块限制测度，允许单元边界落在原开域外而不做错误集合包含。原 Q_h jet 的值 a.e. 等于实际函数，减法线性性由真正原值唯一性证明。定义真正误差 jet；若一个原 H¹ jet 的值在闭单元被实际 Q_h 再现，则减去它不改变误差的局部值及所有弱场。没有要求一般 H² 函数的节点取值，也没有假设投影弱梯度线性性而不证明。

`CartesianKuhnErrorStability` 对全部原 H¹ jet，以 T095 已接受的实际 Q_h 梯度稳定性和 T093 的常数1局部 L² 稳定性，证明误差的单元 H¹ 缩放范数≤(A+2)倍真实裁剪块上输入的 H¹ 缩放范数。h·(A/h)严格消去，所有 Lp 代表替换及单元/邻域测度转移均在 a.e. 层证明。

`CartesianKuhnLocalError` 从 T094 获得原 H²∩H¹₀ 状态的边界相容仿射 p、实际局部弱 H¹ 残差 r 及其统一 h² Hessian 界。p 用真实仿射系数 jet 在整个原有界域上实现；其原 L² 值精确等于此前 Q_h 再现使用的 boundedAffineLp p。真实全域残差 U-P 在实际裁剪块的弱限制严格等于 r（由值唯一性），所以其值和真实弱梯度范数均可替换为 r 的范数。局部误差不变性和稳定性与 B.1 界组合，常数为两个先验常数之积。

原域、全状态、全部实际边界层和角点、h 与网格统一性均保留；没有给一般状态赋予节点值、没有使用形式分片梯度替代真实弱导数、没有新增正则性或迹假设。完整允许权 B.2 与 FD 刚度等式尚待。原 paper/main.tex 与固定 Lean/mathlib 未改。

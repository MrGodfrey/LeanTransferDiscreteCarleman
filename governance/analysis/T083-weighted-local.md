# T083：原允许权族的全部全局 H²∩H¹₀ 局部边界逼近

四模块9声明，AUXILIARY，为 B.2 的实际局部加权步骤供应证明。原文保持13/26；尚未完成实际 FD 矩重构和全域有限重叠组合。

`LocalWeightedNorm` 将原全局 BoundedMultiplier 限制到真实子域，保留同一实际权函数，证明乘权与实际 L² 限制交换。对任意标量或向量 L² 场，实际 a.e. 比较 `|σ|≤Ws` 和 `s≤W|σ|`、s>0 分别给正向乘权界和反向去权界。未改换能量或取代表点值。

`WeightedLocalBoundaryAffine` 对任意原全局 H²∩H¹₀ 状态，用 T082 内部产生的真正局部零迹应用 B.1。局部盒各边长与 h 双向可比，所选整个闭面在原域物理边界上。输出同一实际仿射多项式 p、完整弱 H¹ 残差 r，其值 a.e. 为原全局 u−p，p 在全部所选闭面上逐点为零。正向局部加权和反向 Hessian 去权抵消锚点 s，得到

`||σr|| + h||σ∇r|| ≤ C h² ||(σ D²u)|_B||`。

右端是原全局加权 Hessian 的真正局部 L² 限制范数。常数仅由维数、边长比较 κ 和权比较 W 决定，位于域、盒、h、面集、实际权、锚点和原状态之前；不依赖 s。

`BoxAllowedComparison` 从实际物理盒直径界、固定空间轮廓的 Lipschitz 界，以及原条件 hq≤1，证明实际允许权 `q^τ exp(ηρq)` 在盒内的双向比较，常数为 `exp(L d κ)`。空间点都在实际盒内，内部转为原域闭包点；两个符号由 |η|=1 覆盖，τ 任意，时间权及周期任意。空间比较中的 q^τ 精确抵消，h q 的上界控制指数，因此常数不依赖 q、τ 或周期。

`AllowedLocalBoundaryAffine` 在固定开凸域、紧闭包与原实际 C¹ 空间轮廓下，先由已证明的光滑轮廓定理内部取 Lipschitz 常数，再取上述 W 和最终 C。全部盒、h、面集、TimeWeight、τ、t、η、原 H²∩H¹₀ 状态均在 C 之后量化。真实盒非空给内部锚点，实际允许权严格正；由真实限制测度 a.e. 盒成员资格及前一比较定理，内部供应所有权比较条件。最终不要求用户提供锚点或比较前提。权正负号和周期统一性完整保留；未对原状态要求光滑、连续或可取点值。

本批只证明局部实际仿射逼近的加权版本。没有将任意稳定、再现仿射的抽象算子当成原 Q_h，也未声称原 Kuhn 网格的节点星、矩条件、局部重构稳定性或有限重叠已实现。完整 B.2/P026 与 FD/P012 保持未完成。

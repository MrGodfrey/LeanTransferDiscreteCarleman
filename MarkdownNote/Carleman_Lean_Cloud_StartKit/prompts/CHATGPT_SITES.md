# 交给 ChatGPT Work / @Sites 的网站提示词

为一个长期的 Lean 数学论文形式化项目创建私人进度仪表盘 website，数据字段和 UI 以本包 `docs/` 的静态原型与 `state/progress.json` 为参考。

展示 M0–M6 里程碑、已审核定理数、条件性定理与完整定理的明确区别、最近一次 Lean CI 状态及 commit、在途 Codex 任务、最近成果日志、额度/credits 状态和官方来源。无法核验的 token 数必须显示“未取得”，不能默认为 0。展示最后更新时间和状态过期提示。

优先将 GitHub 中已批准的状态文件作为唯一可信数据源；实际产品权限若无法让个人账号中的 Sites 定时访问私有 GitHub，则明确标注当前只是快照，不要假装实时连接。默认仅向站点所有者开放，不要暴露论文 PDF、代码仓库私密信息或登录令牌。先生成私密预览，用户审核后再发布。
